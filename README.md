# ☕ Coffee Website

A modern and responsive coffee shop landing page built using HTML and CSS. This project focuses on creating a clean user interface, responsive layouts, and an enjoyable user experience.

---

## 🚀 Features

- ☕ Modern Coffee Shop Landing Page
- 📱 Fully Responsive Design
- 🎨 Clean and Attractive UI
- 🧭 Navigation Bar
- 🖼️ Image Gallery Section
- ⭐ Why Choose Us Section
- 📋 Services Section
- 📞 Contact Section
- 💻 Pure HTML & CSS (No Framework)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Boxicons
- Google Fonts
- Responsive Web Design
